# Code of Conduct

## Our standard

We are committed to a respectful, welcoming, and harassment-free community.
Contributors should communicate constructively, assume good intent, accept
technical feedback gracefully, and focus criticism on ideas and code rather
than people.

Unacceptable behavior includes harassment, discrimination, personal attacks,
threats, deliberate intimidation, publishing private information, or sustained
disruption of project discussions.

## Scope

This standard applies in issues, pull requests, reviews, discussions, and other
spaces where someone represents the project.

## Enforcement

Maintainers may edit or remove inappropriate contributions and may temporarily
or permanently restrict participation. Report conduct concerns privately to a
maintainer through their GitHub profile rather than opening a public issue.
Reports will be handled as confidentially as practical.
